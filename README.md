# ผจญภัยประจวบฯ – Trivia Adventure

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ไม่ต้องติดตั้งอะไร)

## โครงสร้างไฟล์
- `index.html` โครงหน้าเว็บ และฉากหน้าปก (SVG)
- `css/base.css` ธีม พื้นหลัง แถบสถานะ แผนที่ ปุ่มเดิน
- `css/hero.css` ตัวละครผู้เล่น
- `css/modal.css` หน้าต่างคำถาม
- `css/cover.css` หน้าปกและแอนิเมชัน
- `js/data.js` แผนที่ ด่าน และคำถามทั้งหมด **(แก้/เพิ่มคำถามที่นี่)**
- `js/util.js` ตัวช่วยพื้นฐาน
- `js/state.js` สถานะเกม (ด่าน ตำแหน่ง คะแนน)
- `js/hero.js` ตัวละครและการวางตำแหน่ง
- `js/game.js` ตรรกะเกม (เดิน ถามตอบ ให้คะแนน)
- `js/cover.js` หน้าปกและเมนู
- `js/main.js` จุดเริ่มเกม

ลำดับการโหลดสคริปต์ใน `index.html` สำคัญ ห้ามสลับ (data → util → state → hero → game → cover → main)
